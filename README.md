# sovet

Служебный репозиторий экосистемы «Собор» (голосовая ОС управляемой организации).

Историческое название модуля «Совет». Актуальная разработка модуля ведётся в `sovet_2`.

## Экосистема
- `ustav_v3` — нормативная память (как работа должна происходить)
- `sobor-cycle-v2` / `sobor-*` — операционно-управленческая память
- `sovet_2` — память развития способности
